# 图书、杂志详情移动端适配

适用宽度：760px 及以下。入口：portal.html 图书详情、pages/index.html 普通杂志详情。

- 首屏采用封面＋标题和元信息，封面宽 88px；360px 以下为 76px。标题允许换行。
- 操作按钮两列等宽，高度至少 44px；领读人卡片独占一行。
- 图书作者、出版社只显示一次；移动端隐藏重复的能力图标，保留带名称的工具卡片。
- 简介正文 15px/26px；简介超过 6 行、编辑推荐超过 4 行，显示“展开全文／收起”。原始段落文字不由此功能裁剪。
- 目录标题统一 20px/28px；杂志栏目标签自动换行，相关杂志两列排列。
- 保留原返回处理及目录交互；有顶部返回的详情页不显示底部导航。
- 桌面不显示新增封面，不应用移动端布局。

实现：resource-detail-mobile.css、resource-detail-mobile.js；封面由 book-sidebar.js 和 pages/scripts/periodical-layout.js 输出。

验证：320/390/430px 无横向页面溢出；390px 图书与杂志截图见 preview/resource-detail-mobile-20261104；1440px 两种详情页无横向溢出且新增封面隐藏；图书目录折叠/展开正常；三个修改的 JavaScript 文件通过 node --check。当前样例简介较短，展开按钮保持隐藏，尚未用实际长简介验证点击。

## 阅读页目录浮层

760px 及以下，带目录的文章/章节阅读页在原阅读工具区增加“目录”按钮，默认不展开；点击从底部打开原生模态浮层。目录沿用原链接、当前篇目标记与章节工具。关闭按钮、点击遮罩、Escape 或选中目录链接均可收起；关闭后焦点回到入口。桌面仍保留侧栏目录；无目录的文章不增加入口。实现文件：reader-mobile-toc.js/css，仅 portal.html 引入。

验证：390px 浮层无横向溢出；目录链接点击后浮层关闭且入口不重复；Escape 关闭并恢复焦点；1440px 还原侧栏且隐藏入口。截图：preview/resource-detail-mobile-20261104/reader-directory-390.png。
