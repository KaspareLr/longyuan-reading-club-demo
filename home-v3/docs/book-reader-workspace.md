# 图书阅读工作区

更新：2026-10-19。仅修改新 Demo，未发布。

## 已确认的界面要求

- 底栏参考 Figma 242:10125。非选中图标 40×40；相邻功能间距 10px；选中项宽度随文字自然展开，左右内边距 4px / 24px，图标文字间距 10px；两组功能间距 40px，笔记与知识图谱间距 20px。移除 AI 对话。
- 原文本、增强文本、Anki 卡片、音频课、自测、知识地图在文章区域内切换。保留当前章节。图书详情的能力入口进入对应阅读模式。
- 不展示“示例”“演示”“本地导读”等说明，不提供返回外部原站的按钮和文案。
- 私人笔记是独立原生 dialog 侧栏，不替换当前学习视图。可保存、编辑、删除及按本章筛选；使用 book-learning-notes 存储。
- 文章评论使用 articleComments 存储，显示“读者评论／写下评论／发表评论”。首次初始化保留旧 notes 中的公开评论。个人阅读笔记计数取私人笔记，不再计入评论。
- 自测入口为独立卡片，拉开标题、说明、题目信息和开始按钮的距离。

## 完整音频课

《希腊古典时代的科学》，452.77 秒，9 个同步知识图。课程讲稿由本项目编写，通过本机语音生成后编码为 AAC，文件位于 assets/book-reader/audio/greek-science.m4a；没有复制原站音频。

支持播放、暂停、拖动进度、前后 15 秒、倍速、音量、静音、循环、课程段落跳转、自动同步知识图、手动翻图、全文稿及进度恢复。HTTP 模式先完整加载 Blob，兼容不支持 Range 的本地 Python 服务；file 模式直接读取本地媒体文件。切走功能或章节会暂停并保存进度。

book-audio-data.js 保存实测分段时间；scripts/build-reader-audio.py 可从 lesson-script.json 重新生成。脚本依赖 macOS say、ffmpeg / ffprobe。

## 完整知识地图

以希腊古典科学为一套完整内容，20 节点、25 条关系。支持实体 / 别名搜索、五种类型的组合筛选、图谱、章节浏览、实体索引、分类树，画布及节点拖拽、滚轮 / 按钮缩放、键盘平移、适配视图、重置布局、全屏、节点详情、关联实体跳转、关联章节阅读。

知识地图展开为宽版内容，隐藏原左侧目录；退出地图恢复原目录。媒体及学习模式收起不适用的正文工具，保留夜间按钮；手机上避免遮挡播放器。

## 全屏涟漪替换白光扫描

原文本到增强文本改为从点击位置（键盘触发时从增强文本按钮中心）扩散的全屏圆形揭示，持续 1100ms。使用 View Transitions 的整页快照，覆盖最远屏幕角落；不支持时使用扩散光环降级。反向切换不播放涟漪，遵循减少动态效果设置，切换或卸载时清理动画。
