### 特例参数

- `index.html?recommendation=book|magazine|article`：只决定首页同一个推荐位的资源类型；不代表三套产品首页。
- `?lecturers=1`：所有相关页面只用一个领读人；领读人首页直接进入该人的个人主页。
- 两个参数可组合，如 `index.html?recommendation=article&lecturers=1`。
- `preview-scenarios.js` 会在同站 HTML 跳转时传播单领读人参数。
- `portal.html#/article/0?context=magazine&resource=第一财经`：期刊文章。
- `portal.html#/article/0?context=book&resource=rb-ob-01`：图书章节。
- `portal.html#/article/shared-0`：独立文章。
- 注意区分 URL 的页面查询参数与 `#` 后路由查询参数，不能交换位置。

## 4. 全站硬约束

1. 图书封面2:3；杂志封面14:19；非杂志文章封面2:3。正文插图、头像、播客方图、活动海报不是封面，不强套比例。
2. 普通图书／杂志浏览与共读是不同场景；普通详情不能泄漏领读、共读内容。
3. 移动断点主要为760px；不得为了手机覆盖PC样式。部分窄屏还有360px等补充规则。
4. 功能图标使用本地 iconfont。品牌、封面、头像、智能体能力入口等允许保留原图片。
5. 阅读正文原字不能改、不能少；改变呈现角色不能复制或漏掉同一段。
6. 正文版心相对整个视口居中；工具栏不占一列，不用右侧padding把正文挤向左。
7. 文本上限分录入、预览字数、展示行数。列表省略不等于允许截掉原数据；当前页必须读完的说明应提供展开。
8. 尊重 `prefers-reduced-motion`；图片／控件动效不能让正文长期不可见。
9. 大多数账户、会员、报名、收藏、笔记及打卡是浏览器本地演示，不代表生产服务接入。

## 5. 首页的修改清单

### 5.1 页面与数据结构

- 首页顺序：身份区 → 一个编辑推荐位 → 每日一读 → 共读 → 精选图书 → 精选杂志 → 播客 → 精选文章混排 → 活动。
- 主推荐只有一个位置，有图书、杂志、文章三种类型。
- 图书／杂志主推荐：推荐标题和推荐长正文独立于书刊名；资源卡含导读、为什么选它。
- 文章主推荐：文章标题和详情、为什么选它；不套图书／杂志的导读字段。
- 推荐信息与图书首页banner共用字段：banner保留书名、作者；下方为推荐正文；对应导读和为什么选它复用同一数据。
- 精选图书卡片副信息为作者；精选图书与全部图书的卡片字段和样式统一，并复用目录数据。
- 精选杂志复用其他页面数据，优先使用`-z`封面素材。
- 精选文章实际是杂志、图书、播客、文章四类混排；按类型进入对应详情。

主要文件：`home-v3.js/css`、`home-v3-data.js`、`catalog-content.js`、`shared-content.js`。

### 5.2 每日一读

- 固定6个资源条目；卡片按资源类型遵守封面比例。
- PC卡高480px，移动端360px；移动卡片与字号缩小，保持横向滑动。
- 首次加载首卡左边缘与页面内容版心对齐；PC不是贴浏览器最左边，手机按内容留白对齐。
- 每张卡片都是渐进模糊；不能把所有卡片改成同一块均匀模糊。当前用多层mask与逐层blur实现，最强50px。
- 遮罩与外卡共享圆角，避免底部／边缘漏出；保留对应的渐变配色。
- 混排列表的播客方形封面不叠加播放图标；独立播客或每日一读的播放入口按各自设计保留。

文件：`home-v3.js/css`、`cover-ratios.js/css`。历史注释中的“单个固定blur层”已被后续渐进模糊实现覆盖。

### 5.3 领读人、共读与移动布局

- 领读人姓名与身份标签在同组，不让标签被强行推到卡片另一端；元信息按字段规则省略。
- 移动端首页隐藏“成为会员”按钮，保留领读人卡片。
- 主推荐移动布局重组图文、导读和推荐理由；不额外显示“查看完整推荐”作为重复跳转入口。
- 共读封面保持固定，不再播放封面缩小的滚动效果；进度动画保留。
- 首页共读“查看全部”为主操作，去共读首页；加入操作降为次要。
- 手机进度区、参与头像、日期和任务内容重新编组，避免进度数字／文字挤在圆环中。
- 状态标签按内容宽度显示，不允许“已完结”被拉成通栏。

文件：`feature-progress-only.js`、`reading-home.js/css`、`reading-list-cards.js/css`、`home-v3.css`。

## 6. 导航、返回与点击区域

### 6.1 当前有效的移动导航

- 顶部只显示Logo与账号：未登录为“登录”，登录后只显示头像。
- 底部一级：首页、阅读、活动、会员。
- 点击阅读进入共读，同时底部切为共读、领读人、杂志、图书；这些都属于一级“阅读”。
- 初次阅读默认共读；直接进入四类首页时选中对应子项。
- 二级左侧返回按钮回首页，恢复一级首页选中。
- 进入二级时胶囊右端固定、左边缘右移收窄，返回圆钮从左侧滑入；返回时反向扩宽。当前过渡360ms。
- 有顶部返回的详情页隐藏底部主导航；没有“更多”托盘，没有首页顶部四标签。
- 领读人图标Male；杂志图标Magazine-2。
- PC仍使用原顶部导航；账号昵称的宽度／省略约束跨页统一。

文件：`mobile-navigation.js/css`、`shared-navigation.js/css`、`local-icons.css`。

### 6.2 手机顶部返回上一级

- 移动返回不再调用浏览历史后退：不会因为切换过文章而回到上一篇文章。
- 杂志文章 → 所属期刊详情；图书章节 → 所属图书详情；独立文章 → 首页文章列表。
- 图书详情 → 图书首页；活动详情 → 活动列表。
- `pages/`复用详情按页面父级地址返回；播客顶部已有固定首页入口。
- PC历史后退行为保留；浏览器自身后退按钮不被重定义。

文件：`portal.js`的`parentRoute()`、`page-motion.js`、`pages/scripts/club-demo-navigation.js`。

### 6.3 移动整条点击

- 唯一跳转目标的条目，空白、文字和图片区域都能激活原链接。
- 多个链接指向同一URL仍算一个目标；指向不同URL时保留原分区。
- 播放、进度条、收藏、表单、展开等独立控件不被整卡跳转抢占；已有整卡a/button不包第二层。
- 用户选中文字时不跳转；不在touchstart上跳转，保留滑动。
- 正文、弹窗、聊天区不接管。PC不启用。
- 覆盖推荐、混排、活动、书刊卡片、共读、领读人、目录／章节等；新条目可以显式加`data-mobile-entry`。

文件：`mobile-entry-targets.js`；细节见[MOBILE-ENTRY-CLICK-RULES.md](MOBILE-ENTRY-CLICK-RULES.md)。

### 11.3 字号与文字角色

| 角色 | 标准 | 大号 | 特大号 |
| --- | --- | --- | --- |
| 正文：字号/行高px | 16/28 | 20/32 | 24/36 |
| 正文小标题、副标题、导语字号 | 24 | 30 | 36 |
| 图表标题、人物图组姓名、图注 | 16/28 | 20/32 | 24/36 |
| 辅助小字字号 | 12 | 13.33 | 16 |

- 文章主标题不受阅读字号控制，保留原响应式尺寸；不要误用正文1.5倍规则。
- 导语文字居中，短装饰线也居中；图表标题不是章节，不加章节方标。
- 小字最低12px；图注不属于辅助小字。正文、段落节点与行高直接绑定三档，避免只改标题不改正文。
- 正文请求字重350，强调650、标题保留层级；系统静态字体不支持350时可能仍匹配400，不能保证跨设备都等幅变细。
- 段间距1em，即16／20／24px；段间距与行高独立。

### 11.4 图文、装饰、收尾

- 图片保持自然尺寸，仅超宽等比缩小；不强制拉满、不裁切，无点击放大／跳原图／zoom-in。
- 图居中，图片相关标题与图注居中，同正文字号；清除继承的32px图片上下margin。
- 图到图注6px，图表标题到图8px；完整图文组距正文PC上下各48px，手机各32px。
- 章节小方标、低对比双栏间线、导语短线、重点引文装饰引号、END细线收尾。
- 引言装饰引号为文字3em、行高0.8，去掉左侧竖线；原文文字不得因引号装饰增加一份副本。
- 隐藏排版器额外添加的文末“原文来源”UI，但数据仍记录出处；原文自身图注与来源不能删除。
- END为非正文装饰、aria-hidden，不进入目录和正文保真比对。
