# 全站封面比例规范

适用：新版分支 longyuan-reading-club-home-v3 的四个入口及其动态页面。此要求覆盖旧版CSS和旧设计里冲突的封面比例。

| 资源类型 | 宽:高 | 覆盖位置 |
| --- | --- | --- |
| 图书 | 2:3 | 首页推荐、精选图书、全部图书、推荐缩略图、详情、目录、共读、领读人资源列表、立体书与翻页转场、实验阅读页 |
| 杂志 | 14:19 | 首页与每日一读中的杂志、刊库、期刊详情、往期/相关期刊、目录、共读、封面书架与立体刊物 |
| 独立文章 | 2:3 | 首页文章推荐、每日一读文章卡、混排列表文章封面、独立阅读详情的封面 |

杂志文章中的正文配图保持原有处理；播客方形封面、人物头像、图标、活动海报不属于上述封面，不能一概裁成竖图。正方形“图书展示区”可以保留，但里面的书封必须2:3。立体透视后的屏幕投影允许变化，书封平面和模型本身的宽高必须符合规则。

## 实现约束

- 所有入口最后加载 cover-ratios.css / cover-ratios.js，统一覆盖历史断点中的冲突。不得在某页再写相反的固定高度/比例。
- 显示比例由资源类型决定，不由源图片天然宽高决定。封面使用object-fit:cover，不拉伸图像；保留原图片文件。图书始终2:3，即使旧素材原始比例接近14:19。
- 宽度驱动时固定宽度、height:auto；高度驱动时固定高度、width:auto。禁止同时用不匹配的固定宽高；不能只设置aspect-ratio却保留冲突的height。
- 新组件可在封面图片上显式写data-cover-type="book" / "magazine" / "article"，由共用脚本规范为data-resource-cover；source/type变化时保持该语义正确。共用组件的封面外框可用data-cover-frame-kind声明类型。
- 脚本按现有组件类型和共用目录资源记录补齐历史图片标记，监听动态插入及src变化；不修改内容数据。不得靠文件扩展名判断书、刊、文章，也不得给所有img统一比例。
- 每日一读仍固定6篇不同资源。桌面卡高480px，书/独立文章宽320px、杂志宽353.684px；<=760px手机卡高360px，书/独立文章宽240px、杂志宽265.263px，初始从首张左对齐。比例不随尺寸改变。
- 保留既有缩略图切换、合页/翻页效果、手机导航和阅读目录浮层。图书翻页和水浒立体模型的封面几何也使用2:3。

## 验证

2026-11-04检查23个页面/模板状态，390px与1440px共46组，累计701个封面布局测量，无超过1.25px舍入容差的比例偏差，也未发现页面横向溢出。SVG图标和杂志文章正文配图均未被标记。记录见preview/cover-ratios-20261104/checks.json。

入口及页面状态包括：首页3种推荐、共读、领读人、图书详情、独立文章、图书章节、杂志文章、书库、刊库、杂志详情、领读详情、领读人详情、活动及详情、会员、个人空间、刊社、旧期刊网首页、旧图书详情、创建向导及水浒实验页。对立体封面按布局尺寸检查，不把透视投影误判为比例错误。
