# 读书会移动端适配说明

日期：2026-11-04。适用原版读书会项目。

## 调整内容

- 建立手机端统一比例：左右留白 16px，主标题约 28–34px、栏目标题约 22px、卡片标题约 16–20px。输入框保持 16px，正文使用独立阅读字号。
- 导航统一为紧凑两行结构；最长文案允许增加行数。实际导航高度由 ResizeObserver 测量，正文自动避让；阅读助手移到右下角并避开阅读器操作栏。
- 首页领读卡片在手机上直接展示图文与进度，取消大封面的滚动占位。精选文章改为小竖图配文字，每日一读缩小卡片宽度；两处图片均保持 2:3。
- 共读页缩小任务圆环，将领读进度调整为通栏，共读列表使用小封面与文字并排。
- 领读人页缩减固定留白；领读人详情使用姓名、小头像并排结构，介绍紧接身份信息显示。
- 书库与刊库主推区域采用图文并排，小缩略图控制在 64px；缩减封面与首屏高度，修复阅读进度文字被挤成窄列的问题。
- 收紧期刊详情的固定大间距，统一活动、会员、个人空间、图书详情与弹窗的字号和内边距。
- 阅读器、音频课、Anki、测验、增强阅读、知识地图及笔记面板同步处理移动端尺寸；正文保持可阅读，图谱仍可拖拽浏览。

## 实现入口

- `mobile-adaptation.css`：手机及窄平板的布局和比例规则，覆盖四个页面入口。
- `mobile-adaptation.js`：测量导航实际高度，响应视口、导航换行和字体加载变化。
- `feature-cover-scroll.js`：手机视口直接显示领读卡片；桌面继续使用原有封面滚动逻辑。
- 入口：`index.html`、`portal.html`、`pages/index.html`、`water-margin.html`。
