# 移动端导航（Figma 511:5323 / 511:5337）

本规则覆盖此前首页展开二级的方案，<=760px生效，PC不变。

- 一级：首页、阅读、活动、会员。首页直接进入当前推荐首页，不展开二级。
- 阅读二级：共读、领读人、杂志、图书；左侧48px返回圆钮＋右侧胶囊，沿用原材质、图标、字号和间距。初次点击阅读进入共读。
- 四个阅读首页直接进入时显示对应二级选中项；二级返回跳转首页并恢复一级导航，首页高亮。导航与页面使用短淡入位移动效；减少动态效果偏好下关闭动画。
- 首页、活动、会员始终展示一级导航。详情页顶部返回出现时，整条底栏隐藏，沿用原返回行为。
- 顶部仅Logo和账号；无顶部切换、无更多托盘。未登录为登录，登录后头像。
- 触摸范围、系统安全区、焦点恢复和aria-current保留；书刊封面与页面内容不受导航调整影响。

## 2026-11-05 细化过渡
- 点击一级“阅读”：胶囊右边缘固定，宽度从整行收窄58px、左边缘向右移动；返回按钮同时从左侧64px外滑入并淡入。分类切换为共读/领读人/杂志/图书，默认共读。
- 返回：返回按钮向左移出并淡出，胶囊同时向左扩宽58px，内容恢复一级导航；完成后回首页。
- 共360ms，cubic-bezier(.22,1,.36,1)；内容淡出与导航后半段同步，新页面不重复播放导航入场动画。读取减少动态效果偏好时直接切换。
- 页面动效的全局链接拦截必须让出一级“阅读”点击，由导航协调布局过渡与跳转。过渡可被后续点击取消，旧跳转不得继续执行。
