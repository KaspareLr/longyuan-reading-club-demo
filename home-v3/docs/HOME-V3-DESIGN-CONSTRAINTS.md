# 新首页样式与内容约束（V3）

## 结构和数据类型：不得误读

首页顺序：身份区 → 单个编辑推荐位 → 每日一读 → 共读活动 → 精选图书 → 精选杂志 → 播客 → 精选文章 → 活动。

**顶部推荐是一个位置的三种可能性，绝不是三个连续推荐区。** `recommendation.type` 只允许 book / magazine / article。同一页面只渲染一个类型；开发预览分别用 `?recommendation=book`、`?recommendation=magazine`、`?recommendation=article`，该参数不是用户界面的切换控件。

| 类型 | 左侧 | 右侧 | 字段要求 |
| --- | --- | --- | --- |
| 图书 | 推荐标题、推荐长文本、立即阅读 | 图书信息卡、封面 | 推荐标题/正文独立于书名/简介；有导读、有为什么选它 |
| 杂志 | 杂志封面、信息卡 | 推荐标题、推荐长文本、立即阅读 | 推荐标题/正文独立于刊名/期次；有导读、有为什么选它 |
| 文章 | 文章标题、详情摘要、为什么选它、立即阅读 | 文章配图 | 直接使用文章标题/详情；无导读字段 |

图书/杂志的导读为左侧深色竖线样式，为什么选它为白底独立块；文章的为什么选它为正文下方竖线块，不套图书信息卡。导读与为什么选它不可合并、互相替代或遗漏。

**精选文章是混排栏目**，数据类型必须允许 magazine / book / podcast / article；栏目名称可保留“精选文章”，不能据此把所有条目转换为 article。不同类型跳到各自详情，播客保留播放入口。

### 何时省略、何时增加展开操作

1. 卡片标题、来源、日期属于导航预览：固定行数省略，整个标题或对应详情入口进入完整内容；不为每张卡额外叠加“展开”。内容类型不可因省略而丢失。
2. 推荐长正文、导读、为什么选它属于独立编辑内容，可能不在资源正文里。任何一个字段真实超出字数或展示行数时，推荐区出现一个“查看完整推荐”，通过浮层完整展示该推荐的所有字段，不能只靠资源详情或鼠标悬浮。
3. 未超出时不显示全文入口。浮层不受首页预览字数/行数限制，支持滚动、关闭、Escape和焦点恢复。不要在600px推荐框里展开全文把下方栏目推走。
4. 不可用裁掉半行、淡出且无省略、强制单行缩字、无限增高、隐藏关键信息代替规范。长单词/无空格字符串可断行，不可撑破容器。
5. 详情正文继续使用既有详情页全文/展开规则。输入端超限应提示编辑修改；兼容历史超限数据时才走预览省略。
