# 移动端条目点击规则

仅760px及以下启用。条目有一个唯一的有效跳转地址时，文字、图片和空白区域均可激活原链接；多个链接去同一地址也算一个目标。多个不同地址时保留原分区。

已有整卡a/button保持原交互。播放器、进度条、收藏、展开、表单、链接等交互控件不向整卡冒泡触发跳转；滑动不添加touchstart跳转，选中文字时不跳转。正文、对话框、聊天区不扩大。新卡片可通过data-mobile-entry接入。PC无改动。

共用脚本mobile-entry-targets.js覆盖首页推荐、混排列表、活动、图书和杂志目录卡片、共读卡片、领读人、杂志文章目录、章节条目。动态列表由事件委托直接适用，无需重绑。
