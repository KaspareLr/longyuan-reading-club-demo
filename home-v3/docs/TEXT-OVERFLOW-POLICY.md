# 超长文案与省略规范

生效日期：2026-11-16。适用于Web和移动端。本文件为最终整理版，优先于旧文档的历史条目；不改变原文数据。

## 判断顺序

1. 系统文案保持原样：导航、栏目名称、按钮、表单标签、状态、固定提示，例如“你好！”“为什么选它？”“导读”“领读语”“已完结”。它们不灌入超长测试文案，也不增加遮罩或展开交互。标签下的具体内容另行判断。
2. 用户昵称始终单行省略：导航、个人中心头部、快捷菜单一致，不遮罩、不弹窗、不展开。表单输入保留正常编辑能力。
3. 列表标题和摘要/介绍预览按各自限定行数显示普通省略号，无渐变、不打开全文预览，点击仍进入该条目的详情。
4. 其他内容字段没有卡片包裹时：按实际用途限行；真实超长才在最后一行下半部分渐变；点击原位展开全文、推动下文，不添加“展开全文/查看完整信息/收起”按钮。
5. 其他内容字段位于实际卡片内时：按卡片布局及字段用途限行；真实超长才在最后一行下半部分渐变；点击共用单字段全文弹窗，卡片保持稳定。
6. 文章正文、独立详情主标题、日期/价格/数值等关键事实保持完整。卡片里的任务说明和共读问题不是无限撑开卡片的例外：均最多3行，点击弹窗看全文。

普通section不自动视为卡片。I/M交互由实际容器决定，不允许遗留的inline/modal标记覆盖容器判断。以上例外优先于通用容器规则。

| 用户昵称 | 1 | 普通省略号，不展开 |
| 共读主推卡及共读列表的资源名称 | 2 | 普通省略号，正常条目导航 |
| 搜索/收藏标题 | 2 | 普通省略号，正常条目导航 |
| 搜索/收藏摘要 | 2 | 普通省略号，正常条目导航 |
| 首页精选文章摘要 | 3 | 普通省略号 |
| 活动/专题预览 | 依字段登记，通常3–4 | 普通省略号 |
| 领读人身份卡姓名、头衔 | 各2 | 渐变＋单字段弹窗；固定“领读人”标签与姓名分开 |
| 作者、身份等紧凑辅助字段 | 通常2，依登记 | 卡片弹窗；独立区域原位展开 |
| 共读卡片领读语 | 3 | 列表预览普通省略；独立主推卡渐变＋弹窗 |
| 任务说明、任务范围、共读问题 | 3 | 卡片渐变＋弹窗 |
| 独立读书会简介 | 3 | 渐变＋原位展开 |
| 评论、私人笔记 | 4 | 无卡片原位展开；卡片中弹窗 |
| 编辑推荐 | 4 | 按容器选择原位展开或弹窗 |
| 资源简介、领读人介绍、阅读观点 | 6 | 按容器选择原位展开或弹窗 |

不能把所有内容统一限制成2行。逐字段完整选择器及数值见 `../text-overflow-limits.css`，机器规则见 `text-content-constraints.json`。首页响应式行数沿用 `--v3-lines`，例如移动文章推荐正文的专用行数不被桌面数值覆盖。

## 样式与脚本职责

- `text-overflow-limits.css`：静态行数的唯一视觉配置入口，使用 `--to-limit`；限高直接用CSS `calc(行数 * 1lh)`，不依赖脚本写像素高度；从旧字段表收拢既有行数，再由明确的特殊字段规则覆盖。直接可表达的单行省略、限高、卡片收缩约束留在CSS中。
- `text-overflow.css`：单行/多行省略、末行下半渐变、卡片布局保护、独立字段弹窗和手机底部浮层。
- `text-overflow.js`：读取计算样式 `--to-limit`，测量实际溢出，选择I/M/E/F行为、处理点击/键盘/焦点和路由更新。不是所有已限行字段都显示遮罩，未溢出的内容无交互。
- `home-field-limits.js`、`secondary-field-limits.js`：保留字段登记和输入上限等兼容功能；其旧行数只作为无CSS预算时的后备，不作为覆盖现行CSS的依据。

例子：

```css
.my-card .summary { --to-limit: 3; min-width: 0; overflow-wrap: anywhere; }
```

新字段应同时接入字段登记或显式声明 `data-overflow-mode`，脚本才能测量并提供交互；只写变量不会自动把任意文字变成可展开控件。列表使用 `data-overflow-mode="ellipsis"`，其余内容由容器判定I/M。`data-overflow-lines`为兼容声明，现行CSS预算优先。

## 卡片保护与交互

- flex/grid文字列及中间容器设置min-width:0；网格使用minmax(0,...)；长无空格串允许断行，禁止撑宽页面。
- 不通过缩小字号、拉伸封面、整卡overflow:hidden来隐藏问题，避免裁掉封面立体效果、阴影或按钮。
- 移动共读列表封面与右侧状态标签顶对齐；文字增多不改变为垂直居中。
- 保留DOM及源数据全文，不用slice/substring删字来满足显示长度。
- 展开与弹窗仅作用于所点击的字段，不能同时触发整卡导航；独立收藏/播放控件照常使用。
- 支持Enter/空格；普通省略条目不新增按钮角色或无效焦点；真正溢出的字段才可展开。
- Web弹窗居中，手机底部贴齐左右视口，最大80dvh并保留安全区；内容内部滚动，关闭后恢复焦点。支持关闭图标、Escape、点击背景。

## 验证版与维护

验证版位于 `../overflow-lab/`，内容文案在渲染后临时替换，不回写正式内容。系统标签/状态/日期数值不参与灌长文；没有干扰阅读的固定悬浮场景入口。入口为该目录 `overflow-check.html`。

检查未溢出、中文长段、无空格英文、手机窄屏、卡片稳定性、弹窗位置、正常条目跳转、原位展开及跨断点重排。用户已确认此前超长控制效果；本轮CSS归并需做回归，代码检查不能代替实体设备视觉验收。
