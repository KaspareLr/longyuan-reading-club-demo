# 搜索功能与场景预览（2026-11-13）

## 线上核对依据

参考 https://readclub.icitychina.net/longyuan/search 。已实际检查文章、刊物、图书、音频切换与结果结构。

- 关键词入口提示书名、刊名、作者或文章标题。
- 类型有文章、音频、图书、刊物，显示各类型数量；线上允许多选。
- 文章类型出现刊物、年份、期号、栏目。刊物类型出现刊物、年份、期号，不出现栏目。图书与音频没有刊物维度。
- 文章结果包含类型、标题、摘要、刊名、年份、期号、栏目；图书包含书名、作者；刊物包含刊名、期；音频包含标题。整条结果可跳转。
- 有清空筛选、结果数量、分页，线上每页20条。

## 当前 Demo 规则：Figma 592:2520（2026-11-13 更新）

本节覆盖早期“仅杂志显示筛选、整期／刊内切换”的方案。以用户当前设计为准：

1. 搜索是独立页面 `portal.html#/search`，Web内容居中限宽960px，顶部100px，结果区左右内缩40px。
2. 标题居中：英文12/18、标题40/52、说明16/26；搜索条上方40px、下方80px间隔。搜索条为白色半透明圆角胶囊，输入、清空、资源类型在同一行。按Enter或输入停顿250ms检索。
3. 类型次序与名称为：全部、图书、刊物、文章、音频。选中类型使用白底阴影，不是黑底，不显示类型数量。
4. **全部、文章、刊物**选中时展示**刊物、年份、期号、栏目**四个下拉；**图书、音频**不展示这些条件。没有“刊内文章”或“整期杂志”的额外维度。
5. Web四个下拉位于结果标题右侧，始终可见；左侧显示结果标题与数量。移动端在独立窄屏结构中提供筛选开关及两列表单。
6. 条件选项基于本地实际数据计算。可直接选择任一维度；选择父条件会更新后续可选范围。刊物改变清除年份、期号、栏目；年份改变清除期号、栏目；期号改变清除栏目。切换资源类型清除四维筛选及页码，保留关键词。
7. 刊物结果表示整期资源；栏目条件按已知目录的栏目集合筛选该期。文章结果按对应文章的刊物、年、期、栏目筛选。全部范围的刊物条件只保留具有对应期刊元数据的资源。
8. 图书、刊物行展示封面、类型、标题、作者／期；文章展示标题、摘要和来源。无封面文章及音频使用纯文字行，不制造占位封面。封面数据复用原项目真实素材，比例遵照现有规范。
9. 书封88px宽，标题20/32，摘要14/20，辅助文字12/20；条目间20px内距与底部分隔线。所有条目整体可点，超长字段继续使用统一遮罩／字段弹窗规则。
10. Demo每页8条，保留结果数量、分页、关键词高亮、清空筛选；筛选状态写入URL。搜索本地标题、作者／来源、摘要，不伪造线上内容数量，不声称已接入线上全文搜索。

文件：`club-search.js`、`club-search.css`；`portal.js`注册路由，`club-features.js`提供入口。图标沿用用户指定本地iconfont，不引入临时Figma资源URL。
