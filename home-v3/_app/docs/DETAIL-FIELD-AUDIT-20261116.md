# 首页、领读人页、共读页：二级详情字段展示位核对

日期：2026-11-16。按当前本地源代码核对，不把测试版临时长文当成正式业务数据。本次只统计与改进验证文案，**没有擅自增加详情模块或修补正式内容字段**。

## 范围与统计口径

“领读页”按领读人列表和领读人主页理解，同时包含其“领读内容”跳转的共读详情；“共读页”为portal的共读首页、主推任务卡和共读列表。首页覆盖图书/刊物/文章三种推荐及每日一读、精选资源、播客、活动。

每行是一种“来源页面＋模块＋内容字段组”，不是每条资源实例；同类重复卡片合并统计，不按屏幕数量翻倍。时间/地点等少数成组元信息同列，主办嘉宾独立列出缺位。图片、按钮图标和所有系统标签不逐个枚举。

本次共登记 **71 项**：一级专用 7 项；有位未贯通 42 项；缺少展示位 14 项；同源贯通 8 项。

| 状态 | 含义 |
|---|---|
| 同源贯通 | 确实读取同一对象/同一字段；少数明确标注为两端固定demo数值 |
| 有位未贯通 | 详情有相应语义区域，但数据源、命名、数值或具体内容未统一 |
| 缺少展示位 | 资源/计划字段需要跨页追溯，但目标详情没有显示该字段的区域 |
| 一级专用 | 首页运营推荐语、页面导语等，可合理只在一级显示，不自动认定设计遗漏 |

## 重点结论

- **图书推荐**：①推荐正文→详情图书简介，③推荐理由→编辑推荐，两个都“有位未贯通”；②导读确实没有详情展示位。推荐标题是一级编辑推荐语，不等于书名，需业务决定是否也在详情保留。
- **刊物/文章推荐**：详情没有首页推荐理由的专用展示位，刊物也没有推荐导读/推荐正文专用位。首页刊物和文章分支还复用了住宅设计图书的部分文案，这是内容配错，不能仅靠加展示区解决。
- **领读人**：姓名、头衔和寄语都有详情位置，但人物数据分多处维护。曹文轩列表卡片特例把一个共读问题当作人物寄语，与详情slogan不是同一内容。
- **领读人主页内的共读卡片**：“领读语”实际读取todayTask.question，二级“共读问题”也读同一字段，属于**同字段不同名称**，不是缺失。计划起止日期和明确状态才是确实未展示的内容。
- **共读首页/列表**：资源名字、作者/期次、进度等大多有位，但一级硬编码与二级plan没有统一；独立领读语、起止日期、状态存在缺位。主推第一财经的一级期次为2026年12期，二级计划为2026年09期，应先确认是哪一期。
- **路由复核**：共读列表的6本书＋3本期刊，9个id均能在加载的计划中找到。不要把这些全部标成“详情不存在”；当前主要是数据对应和展示位问题。

- `home-v3.js`、`book-recommendation-fields.js`、`home-v3-data.js`：首页三推荐、资源描述及字段来源。
- `script.js`、`clubCatalogData`/`clubPortalData`：首页普通资源与详情的两套集合。
- `portal.js`的bookDetail/article/readingCard、`reading-home.js`：书/文章展示位及共读首页字段。
- `people-home.js`、`people-home-data.js`、`pages/scripts/claimed-community.js`：人物列表和人物详情。
- `pages/scripts/claimed-guided-reading.js`：共读卡片与共读详情，注意start/end/message/description等有数据却未展示。
- `pages/scripts/books-guided-plans.js`、`magazines-guided-plans.js`：资源到计划id扩展。
- `pages/scripts/periodical-layout.js`：刊物介绍与目录，并无独立推荐导读/理由。

建议先确定字段含义和唯一数据来源，再决定补位：优先图书导读、真正的计划领读语/起止日期/状态；其次统一第一财经期次、人物寄语和任务问题；首页运营推荐标题可以单独保留。**不建议为了让每一段文字在二级重复出现而机械增添模块。**
