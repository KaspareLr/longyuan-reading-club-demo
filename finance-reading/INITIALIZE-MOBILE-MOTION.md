# 初始化流程：移动端与交互规范

保持现有黑白、圆角、细阴影和本地图标系统。按 apple-design 技能采用直接反馈、可中断运动、相同进出路径与系统偏好降级，不引入在线动画依赖。

## 已解决的问题

- 320px 时原样式隐藏“上一步”，主按钮换行造成90px高的底栏。现保留返回，主按钮占剩余宽度，辅助说明在手机隐藏；底栏正常72px，并考虑安全区。
- 人群卡片在窄列中拥挤，资源类型和数量控件触控区过小。人群改单列、资源类型按宽度两至三列、数量控件扩大到36–40 × 44px。
- 手机普通输入和数量输入统一16px，减少iOS自动放大；书卡编辑、搜索创建、推荐卡片及领读人重新适配小屏。
- 顶部栏与底部栏高度通过ResizeObserver同步为布局变量；恢复配置时直接定位当前步骤。描述框展开后按最小距离滚动，使正在输入的内容避开操作栏；编辑时不重复显示同一段描述。
- 使用visualViewport处理软键盘出现时的可视区域与底栏避让，保留系统原生滚动与输入行为。

## 统一运动规则

| 操作 | 规则 |
| --- | --- |
| 按下 / 松开 | pointer-down即时反馈；缩至0.96；阻尼比1，无弹跳；响应0.14 / 0.24秒 |
| 选项切换 | 原位更新选中标记与aria状态，不重建整组选项，保留键盘焦点 |
| 新问题 | 标题和内容6px位移与淡入，约0.3秒的临界阻尼回弹；不移动整个页面容器 |
| 补充输入 | 约0.3秒临界阻尼展开；可在未完成时反向收起，从当前高度与速度接续 |
| 进度弹层 | 缩放0.97至1、10px位移和淡入；关闭沿原路径返回，保留原生dialog焦点隔离与Escape |
| 系统偏好 | 减少运动时即时更新；减少透明度时实色背景；高对比度时强化结构边界 |

仅在必要的展开过程中调整局部高度；其他运动使用opacity、translate和scale。缓存未变化的历史对话，避免普通选项操作重复生成大量历史节点。

## 验证范围

通过浏览器视口测试320、375、390、430、768px及1280px；667×375横屏弹层可内部滚动。核对资源配置、数量加减、书卡编辑、图书搜索/创建、运营策略、自然语言描述、推荐、周期/自定义天数、领读人及完成弹层。各测试页面无横向溢出；正常底栏保持70–72px。

验证连续点选、反复展开/收起、草稿重开、发送、弹层完成/关闭/重开及Escape。脚本语法检查和git diff检查通过。系统偏好降级已有实现；真实iPhone/Android软键盘、浏览器工具栏和设备安全区仍需真机体验，桌面浏览器视口不能等同于真机验证。
